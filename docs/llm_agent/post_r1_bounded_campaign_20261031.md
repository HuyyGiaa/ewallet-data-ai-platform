## Resource guard

`ops/llm_agent/host_resource_guard.py` (stdlib only) returns SAFE or UNSAFE.
SAFE needs all of:
- MemAvailable ≥ 10 GiB;
- CPU below 65 % over a sample;
- no swap activity;
- memory PSI below 5;
- Airflow 8084 health endpoint healthy. Process existence alone does not
  count.
